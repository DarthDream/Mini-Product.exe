🛒 Mini Product Management System

A simple product management project developed using Python and JSON. This project is designed to manage product data and practice basic Python programming concepts.

🚀 Features

📦 Load product data from JSON

💾 Save product information to JSON

🔍 Display product information

📊 Work with product prices

🗂️ Store product data in a structured format

🛠️ Technologies Used

Python

JSON

📁 Project Structure

Mini-Product.exe/
│
├── app.py
├── system.py
├── storage.py
├── product.json
└── README.md

⚙️ Installation

Clone the repository:

git clone https://github.com/DarthDream/Mini-Product.exe.git

Open the project folder:

cd Mini-Product.exe

Run the project:

python app.py

📂 Data Storage

Product information is stored in product.json.

Each product contains:

ID

Name

Price

🎯 Project Goal

The main goal of this project is to improve Python programming skills, understand JSON file handling, and practice working with product data.
